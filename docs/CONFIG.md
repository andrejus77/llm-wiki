# Configuration reference

Generated by `manage.py docs_config` from `llmwiki/conf.py`. Every value can be changed in the portal (Agent › Settings) or in `data/settings.yaml` (bootstrap). Saved portal settings win over the YAML file.

## Wiki pages (`pages`)

How the editor writes a wiki page. A page is read INSTEAD of the mail, so it must be shorter than the mail and say
    each fact once: a short summary + sections the editor names itself, the whole page rewritten in one request, held to
    a length budget that grows with the mail behind it. Every limit is checked by the script (guards), not only asked for.

| Setting | Default | Range / options | Description |
|---|---|---|---|
| `pages.structure` | `"free"` | free, template | free = a summary + up to max_sections sections the editor names itself; the whole page is rewritten at once so nothing is repeated across sections. template = the fixed sections per level (Overview, Background, How it works, …), rewritten section by section |
| `pages.summary_words` | `60` | ≥ 20 ≤ 300 | The summary at the top: what it is, where it stands now, what happens next |
| `pages.max_sections` | `4` | ≥ 1 ≤ 12 | Sections after the summary (free structure); a small topic may need one or none |
| `pages.section_words` | `130` | ≥ 40 ≤ 1500 | Max words per section |
| `pages.budget_ratio` | `0.5` | ≥ 0.1 ≤ 3.0 | Page length budget = this × the words people wrote in the page's emails (new text only: no quoted history, no automated mail) … |
| `pages.budget_min` | `120` | ≥ 40 ≤ 3000 | … but at least this many words … |
| `pages.budget_max` | `650` | ≥ 100 ≤ 10000 | … and at most this many words |
| `pages.tolerance` | `0.15` | ≥ 0.0 ≤ 1.0 | A draft over the budget (or a section/summary over its limit) by more than this share → the confirm round asks the editor to shorten it |
| `pages.over_budget` | `"accept"` | accept, reject | Still over after the confirm round: accept (a warning in the history) or keep the old text and retry next run |
| `pages.repeat_check` | `true` |  | Script check for repetition: a sentence that repeats another sentence of the page → confirm round |
| `pages.repeat_similarity` | `0.7` | ≥ 0.3 ≤ 1.0 | Share of the shorter sentence's words that must also be in the other one to count as repeated (the summary vs a section: 0.15 higher) |
| `pages.drop_phrases` | `["\\b(?:the )?(?:sources/emails) (?:do/does/did) not\\b", "\\bnot (?:stated/m…` |  | Regexes (case-insensitive): a sentence matching one is removed by the script — talk about the sources or the page itself instead of facts |

The department addresses (sources.dept_addresses) are separate teams of one bigger department: one wiki, one report each.
